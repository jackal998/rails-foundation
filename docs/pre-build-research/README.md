# Pre-build research

Findings gathered *before* the application exists, kept because they are
expensive to re-establish and because several of them contradict what a
vendor's own marketing pages say.

Each file records **how** a claim was obtained, not just the claim.
`.claude/rules/portable-core.md` §5 sets the tiers: measured on the real
system beats a fetched primary source, which beats recollection. A claim
here that is arithmetic or inference says so in the same sentence.

Nothing in this folder is a decision. Decisions live in
[`../ARCHITECTURE.md`](../ARCHITECTURE.md); when a file here falsifies
something there, it says so explicitly and the architecture document is
corrected separately, by the owner.

## On screenshots

The evidence for these findings was captured as full-screen PNGs of a
signed-in session. **They are deliberately not committed.** A full-screen
capture of a personal workstation carries the bookmark bar, other open
tabs, the taskbar and account identifiers — exactly the class of thing
this repository's `CLAUDE.md` bans from a public repo. The findings are
transcribed instead, verbatim where the wording matters.
